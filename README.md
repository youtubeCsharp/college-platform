# 数字经济与管理学院综合管理平台

二级学院内网专属行政办公台账管理系统:三办分权录入、月度三色日历总览、附件本地归档、
工作安排派发与跟进、智谱 GLM-4-Flash 免费 AI 自动生成当日简讯与月度总结。
**数据全程 Excel 本地存储,不上公有云、无数据库运维。**

---

## 一、运行环境

- Windows 7/10/11(4G 内存普通办公主机即可)
- Python 3.10 及以上(安装时勾选 "Add Python to PATH")

## 二、首次安装(仅需一次)

```bat
cd /d 本平台目录
python -m pip install -r requirements.txt
```

## 三、配置 AI(可选,不配置不影响台账功能)

1. 到智谱开放平台 https://open.bigmodel.cn 注册并实名,在"API 密钥"页免费创建密钥
   (GLM-4-Flash 为长期免费模型,无月租);
2. 用记事本打开 `config.json`,把密钥填入 `ai.api_key`,保存;
3. 重启平台生效。模型名/接口地址也在同一位置,可一键切换其他模型。

## 四、启动

双击 **启动平台.bat**,看到"平台已启动"即可:

- 本机访问:<http://127.0.0.1:8000>
- 手机(连同一校园 Wi-Fi)访问:`http://<部署机内网IP>:8000`
  (查询内网 IP:cmd 运行 `ipconfig`,看"IPv4 地址")

开机自启(可选):把"启动平台.bat"的快捷方式放入
`shell:startup` 文件夹(资源管理器地址栏粘贴即达)。

## 六、日常使用流程

1. **三办录入**:首页点日期 → "登记本办工作" → 填工作大类/内容/完成情况/参与人员,
   可勾选"敏感事项"、可上传附件(照片/简报/PDF 等);
2. **院领导查看**:日历三色圆点看全院节奏,点日期看三办明细(只读);
3. **派活与跟进**:"工作安排"页发布任务 → 责任办在电脑或手机上回复进度;
   回复时勾选"需要学院协调资源"会亮红标,汇总到领导侧"只看需协调资源"筛选;
4. **AI 生成**(需配置密钥):页面底部两个按钮——
   - 生成当日工作简讯/通讯稿;
   - 生成月度工作总结初稿(按三办分板块,自动合并同类事项)。
   敏感条目与全部附件**不参与 AI、不上传外网**;生成结果一键复制后自行润色上报。

## 七、数据都在哪(直接可查可备份)

| 位置 | 内容 |
|------|------|
| `data\台账\综合办.xlsx / 教学办.xlsx / 学生办.xlsx` | 三办台账(物理隔离) |
| `data\任务\工作安排.xlsx` | 任务表 + 跟进回复表 |
| `data\日志\操作日志.jsonl` | 全部操作留痕(只增不删) |
| `files\年-月-部门\` | 附件归档(台账中保存的是这里的路径) |
| `backups\` | 每日自动备份 |

台账允许 **新增、修改、作废**,不允许物理删除;作废记录仍保留在 Excel 中可追溯。

## 八、每日自动备份(建议设置一次)

资源管理器地址栏输入 `shell:startup` 回车,把"每日备份.bat"的快捷方式放进去(开机即备)。
或用管理员 cmd 注册计划任务(每天 23:30 执行):

```bat
schtasks /Create /TN "学院台账每日备份" /TR "本平台完整路径\每日备份.bat" /SC DAILY /ST 23:30
```

## 九、常见问题

| 现象 | 处理 |
|------|------|
| 保存时提示"台账文件正被占用" | 有人用 Microsoft Excel 直接打开了台账文件,请其关闭后重试。日常查数据请走网页,不要双击 Excel |
| AI 提示"网络连接失败" | AI 生成需临时联网;断网时录入/日历/任务等其余功能完全不受影响 |
| AI 提示未配置 API Key | 按第三节填写 config.json 后重启 |
| 手机打不开系统 | 确认手机连的是同一校园 Wi-Fi;校外访问需学校 VPN。**切勿做公网端口映射** |
| 端口被占用 | 记事本改 config.json 中 `server.port`(如 8001)后重启 |

## 十、安全须知

1. 系统仅限学院内网使用,不得映射到公网;
2. "敏感事项"请按学院保密口径如实勾选:凡标记条目、命中敏感词条目的文字,
   均不会提交智谱 AI;非敏感文字台账会经公网调用 AI,如需完全离线可不配置密钥;
3. 台账文件请勿在本平台外随意移动、重命名;换机部署 = 整目录拷贝 + 新机装 Python。
